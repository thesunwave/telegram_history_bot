# Bot Installations

Раздел `/admin/installations` и пункт «Установки бота» доступны только владельцу
экземпляра через его обычный Telegram-вход. Владелец определяется по `ADMIN_USER_ID`
или уже сохранённой привязке `app_settings.scope = telegram_owner`, как в настройках
бота. До привязки владельца доступ закрыт. Отдельные логин и пароль не нужны;
Basic Auth не даёт доступа к разделу.

Остальные пользователи не видят пункт меню и не могут открыть страницу или API
даже по прямой ссылке. Без Telegram-сессии страница возвращает на `/admin`,
а API отвечает 401; чужая Telegram-сессия получает 403. Владелец видит все известные
чаты этого бота, независимо от своего участия в них.
В том числе каталог показывает метаданные личных диалогов: имена/username,
ID, тип чата, статус и даты членства бота, время последнего сообщения.
Текст сообщений здесь не выводится, а доступ к статистике чужих личных диалогов
через обычную админку не предоставляется.

На принимающем экземпляре (`TELEMETRY_RECEIVER=true`) владелец также видит
анонимные ID, даты первого и последнего сигнала (UTC), число дней с сигналами
и диапазоны активности чатов и групп. Счётчики и таблица включают ID, которые
сообщили об активности чатов за 7 дней или прислали сигналы в разные дни.
Разовые сигналы без активности исключены из статистики, поскольку среди них есть
тестовые. Исходные записи сохранены. Таблица показывает до 200 ID, счётчики
учитывают все ID, прошедшие фильтр. Эти данные не показывают число реальных пользователей.

Таблица показывает название и ID чата, тип, статус бота, дату последнего добавления,
последнего изменения статуса и последнего учитываемого сообщения. Счётчики разделяют
активные, неактивные и неизвестные статусы. Личные чаты означают обращения к боту.

Добавления, удаления, блокировки и изменения прав учитываются из `my_chat_member`
в authenticated webhook. При настройке `allowed_updates` необходимо включить
`my_chat_member`; см. [Telegram Bot API](https://core.telegram.org/bots/api#update).
Стандартная регистрация через `/admin/setup` включает этот тип автоматически.
После обновления существующего экземпляра нажмите «Подключить webhook» на этой
странице ещё раз: прежняя подписка Telegram сама по себе не изменится.
Эти события обрабатываются независимо от флагов анализа сообщений.

Старые чаты обнаруживаются по существующим метаданным и статистике D1. До нового события
статус и дата установки неизвестны; наличие сообщений само по себе не подтверждает
текущее членство бота. Telegram API не предоставляет полный исторический список
установок, поэтому ранее неизвестные тихие чаты появятся после нового события.

Метаданные членства хранятся в D1 `app_settings` под `bot_membership:{chatId}` без TTL,
отдельно от семидневной истории сообщений. Обновление версии и статуса выполняется
атомарно, чтобы параллельные webhook-запросы не возвращали устаревший статус.
Текст сообщений и данные пользователя,
добавившего бота, не сохраняются. Список отражает последние полученные события.
Метаданные названий чатов в KV могут обновляться с задержкой.
