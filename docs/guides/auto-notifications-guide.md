# Руководство по автоматическим уведомлениям

Система автоматических уведомлений позволяет пользователям чатов настраивать автоматические рассылки различных типов отчетов и сводок.

## Возможности

### Типы уведомлений

1. **🚨 Криминальные репорты** (`criminal_reports`)
   - Уведомления о нарушениях УК РФ
   - Поддерживает мгновенную отправку при обнаружении
   - Настраиваемый порог срабатывания

2. **🤬 Отчеты о мате** (`profanity_reports`)
   - Статистика использования матерной лексики
   - Ежедневные/еженедельные/ежемесячные отчеты
   - Топ матерных слов и пользователей

3. **📈 Сводка активности** (`activity_summary`)
   - Общая активность пользователей в чате
   - Статистика сообщений и участников
   - Графики активности

4. **📋 Ежедневная сводка** (`daily_summary`)
   - Комплексный отчет за день
   - Включает активность, нарушения и статистику

5. **📊 Еженедельная сводка** (`weekly_summary`)
   - Детальный анализ за неделю
   - Тренды и сравнения с предыдущими периодами

6. **📈 Месячная сводка** (`monthly_summary`)
   - Полная аналитика за месяц
   - Глубокий анализ трендов и паттернов

### Настройки расписания

- **⚡ Мгновенно** (`instant`) - отправка при обнаружении события
- **📅 Ежедневно** (`daily`) - в указанное время каждый день
- **📊 Еженедельно** (`weekly`) - в указанный день недели и время
- **📈 Ежемесячно** (`monthly`) - в указанное число месяца и время

### Дополнительные возможности

- **🔇 Тихие часы** - период, когда уведомления не отправляются
- **🛡️ Контроль доступа** - ограничение изменения настроек только администраторами
- **📊 Статистика** - отслеживание успешности доставки уведомлений
- **🔄 Автоматические повторы** - при неудачной доставке

## Команды

### Основные команды

```bash
# Показать текущие настройки
/auto_notifications status

# Включить все уведомления
/auto_notifications enable

# Отключить все уведомления  
/auto_notifications disable

# Включить конкретный тип уведомлений
/auto_notifications enable criminal_reports

# Отключить конкретный тип уведомлений
/auto_notifications disable profanity_reports

# Показать статистику
/auto_notifications stats

# Показать статистику конкретного типа
/auto_notifications stats daily_summary

# Показать доступные типы уведомлений
/auto_notifications types
```

### Настройка расписания

```bash
# Показать настройки конкретного типа
/auto_notifications schedule daily_summary
```

## Примеры использования

### Быстрая настройка для нового чата

1. Включите общие уведомления:
   ```
   /auto_notifications enable
   ```

2. Включите криминальные репорты (мгновенные):
   ```
   /auto_notifications enable criminal_reports
   ```

3. Включите ежедневную сводку:
   ```
   /auto_notifications enable daily_summary
   ```

4. Проверьте настройки:
   ```
   /auto_notifications status
   ```

### Настройка для активного чата

1. Включите все основные типы уведомлений:
   ```
   /auto_notifications enable criminal_reports
   /auto_notifications enable profanity_reports
   /auto_notifications enable daily_summary
   /auto_notifications enable weekly_summary
   ```

2. Проверьте статистику через некоторое время:
   ```
   /auto_notifications stats
   ```

### Отключение уведомлений

```bash
# Отключить конкретный тип
/auto_notifications disable profanity_reports

# Отключить все уведомления
/auto_notifications disable
```

## Настройки по умолчанию

При первом включении уведомлений применяются следующие настройки:

- **Криминальные репорты**: отключены, мгновенные, порог = 1
- **Отчеты о мате**: отключены, ежедневно в 9:00, порог = 5
- **Сводка активности**: отключена, ежедневно в 18:00
- **Ежедневная сводка**: отключена, ежедневно в 20:00
- **Еженедельная сводка**: отключена, еженедельно в 10:00 (понедельник)
- **Месячная сводка**: отключена, ежемесячно в 10:00 (1 число)

## Права доступа

По умолчанию изменение настроек уведомлений доступно только администраторам чата. Это обеспечивает:

- Защиту от спама
- Контроль над настройками чата
- Предотвращение несанкционированных изменений

## Тихие часы

Функция тихих часов позволяет настроить период, когда уведомления не будут отправляться. Это полезно для:

- Соблюдения режима сна участников
- Избежания уведомлений в нерабочее время
- Концентрации уведомлений в определенные часы

Пример настройки тихих часов с 22:00 до 8:00 (настраивается через код):

```typescript
await service.updateChatSettings(chatId, {
  quietHours: {
    enabled: true,
    startTime: { hour: 22, minute: 0 },
    endTime: { hour: 8, minute: 0 }
  }
}, adminUserId);
```

## Статистика и мониторинг

Система ведет подробную статистику по каждому типу уведомлений:

- **Общее количество отправленных** уведомлений
- **Процент успешной доставки**
- **Среднее время отклика** при отправке
- **Количество ошибок** и причины неудач
- **Дата последней отправки**

Эта информация помогает:
- Отслеживать работоспособность системы
- Выявлять проблемы с доставкой
- Оптимизировать настройки

## Интеграция с существующими функциями

Система автоматических уведомлений интегрирована с:

- **Анализом криминальных нарушений** - автоматические репорты при обнаружении
- **Системой анализа мата** - регулярные отчеты о статистике
- **Счетчиками активности** - сводки активности пользователей
- **Системой сводок** - автоматическое создание ежедневных/еженедельных отчетов

## Технические детали

### Архитектура

Система построена на следующих компонентах:

1. **Модели данных** (`src/core/models/notification-settings.ts`)
   - Определения типов и интерфейсов
   - Настройки по умолчанию
   - Шаблоны уведомлений

2. **Валидация** (`src/core/models/notification-validation.ts`)
   - Проверка корректности данных
   - Санитизация поврежденных настроек
   - Утилитарные функции

3. **Репозиторий** (`src/core/repositories/notification-repository.ts`)
   - Хранение настроек в KV Storage
   - Управление запланированными уведомлениями
   - Статистика отправок

4. **Сервис** (`src/core/services/notification-service.ts`)
   - Бизнес-логика управления уведомлениями
   - Планирование и отправка
   - Обработка расписания

### Хранение данных

- **Настройки чатов**: KV Storage с TTL 1 год
- **Статистика**: KV Storage с TTL 90 дней  
- **Запланированные уведомления**: KV Storage с динамическим TTL
- **Списки чатов**: KV Storage для быстрого доступа

### Обработка расписания

Система поддерживает автоматическую обработку запланированных уведомлений через:

1. **Cron jobs** - регулярная проверка и отправка
2. **Автоматические повторы** - при неудачной доставке
3. **Управление жизненным циклом** - очистка старых уведомлений

## Устранение неполадок

### Уведомления не отправляются

1. Проверьте общий статус:
   ```
   /auto_notifications status
   ```

2. Убедитесь, что уведомления включены для чата и конкретного типа

3. Проверьте, не попадает ли время отправки в тихие часы

4. Посмотрите статистику ошибок:
   ```
   /auto_notifications stats
   ```

### Ошибки доступа

1. Убедитесь, что у вас есть права администратора чата
2. Проверьте настройки `adminOnly` в конфигурации чата
3. Обратитесь к администратору для добавления в список разрешенных пользователей

### Проблемы с производительностью

1. Уменьшите `maxItemsInReport` для больших отчетов
2. Увеличьте пороги срабатывания для менее важных уведомлений
3. Используйте менее частые расписания для объемных отчетов

## Разработка и расширение

### Добавление нового типа уведомлений

1. Добавьте новый тип в `NotificationType`
2. Создайте шаблон в `DEFAULT_NOTIFICATION_TEMPLATES`
3. Реализуйте сбор данных в `collectNotificationData`
4. Добавьте обработку в команды

### Кастомизация шаблонов

Шаблоны уведомлений поддерживают переменные в формате `{{variable}}`:

```typescript
const template = {
  type: 'custom_report',
  title: 'Кастомный отчет',
  template: `📊 *{{title}}*

Период: {{startDate}} - {{endDate}}
Всего событий: {{totalEvents}}

{{#if includeDetails}}
Детали:
{{#each events}}
• {{name}}: {{count}}
{{/each}}
{{/if}}`,
  variables: ['title', 'startDate', 'endDate', 'totalEvents', 'events']
};
```
