# Project Docs

This folder keeps project documentation organized by purpose.

## Structure
- docs/guides/ — user/dev guides and how-to documents
- docs/ops/ — deployment, monitoring, and operational runbooks
- docs/notes/ — implementation notes, analyses, and fix summaries
- docs/debug/ — debugging artifacts (e.g., Postman collections)
- docs/features/ — feature-specific design docs (when needed)

## Naming
- Use lowercase kebab-case for filenames (e.g., "auto-notifications-guide.md").
- Keep titles inside files in Title Case.
- Prefer short, specific names that match the content purpose.
