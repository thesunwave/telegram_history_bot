# Race Condition Tests

Этот проект включает специализированные тесты для проверки защиты от race conditions в системе управления блоками дней.

## Запуск тестов

### Локально

```bash
# Запуск только race condition тестов
npm run test:race-conditions

# Запуск всех тестов (включая race condition)
npm run test:all

# Запуск обычных тестов
npm test
```

### В CI/CD

Тесты race conditions автоматически запускаются в GitHub Actions после основных тестов:

1. Основные тесты (`npm test`)
2. Race condition тесты (`npm run test:race-conditions`)

## Что тестируется

### 1. Concurrent Message Addition
- Проверяет корректность добавления сообщений при параллельных запросах
- Убеждается, что не происходит потери данных

### 2. Duplicate Message Detection
- Тестирует обнаружение и обработку дубликатов сообщений
- Проверяет, что дубликаты не добавляются в хранилище

### 3. High Concurrency Scenarios
- Симулирует высокую нагрузку с множественными параллельными операциями
- Проверяет стабильность системы под нагрузкой

## Структура тестов

Тесты race condition организованы следующим образом:

- **Интеграционные тесты** (`tests/race-condition.test.ts`): Тесты на основе Vitest для валидации выполнения сценариев race condition
- **Основная логика тестов** (`src/race-condition-tests.ts`): Содержит фактические реализации тестов race condition
- **Инфраструктура моков**: Использует стандартизированные генераторы моков из `tests/test-utils.ts` для консистентной тестовой среды
- **Специализированные моки**: Моки для функций day-block-manager для симуляции race conditions

## CI/CD Integration

Тесты интегрированы в GitHub Actions workflow (`.github/workflows/ci.yml`):

- Запускаются после успешного выполнения основных тестов
- Имеют таймаут 10 минут
- Используют verbose reporter для детального вывода
- При падении тестов CI pipeline завершается с ошибкой

## Мониторинг

Тесты race conditions помогают обеспечить:

- Целостность данных при высокой нагрузке
- Корректную работу механизмов блокировки
- Отсутствие дубликатов в хранилище
- Стабильность системы при параллельных операциях
