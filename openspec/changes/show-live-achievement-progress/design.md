## Evidence and scoring

The read path uses the existing achievement rules and a D1 snapshot of aggregates and coverage. Live-owned days use the existing CountersDO proof contract. The open day preview verifies the base counters, so delayed language analysis does not postpone the preview. Closed days and award jobs use the existing full proof. The group preview uses a contiguous verified prefix of the current eligible week. The personal preview uses only eligible owner data and falls back to the saved evaluation when the daily aggregates are incomplete. Forwards and direct replies use their existing independent evidence. The most recent finished week counts toward the consecutive-week condition, with current-week activity shown separately.

## Presentation and delivery

The shared projection supplies numeric conditions and localized copy. Telegram displays them in collection messages and badge captions. The dashboard keeps its scalar fields and adds structured conditions with localized labels. A minute refresh runs while the Achievements page is visible. The client retains the last loaded collection on a transient error, discards stale responses after navigation, and clears cards when access is denied.
