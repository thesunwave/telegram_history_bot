# Требования к улучшенному отображению информации о нарушениях в Telegram боте

## Введение

Данная функция направлена на улучшение отображения информации о криминальных нарушениях в Telegram боте. В настоящее время система получает богатую информацию от LLM анализа, но отображает ее в упрощенном виде. Цель - создать развернутые, информативные сообщения для пользователей с максимальным использованием доступных данных в рамках возможностей Telegram.

## Требования

### Требование 1

**Пользовательская история:** Как пользователь Telegram бота, я хочу получать развернутые сообщения о выявленных нарушениях с полной информацией, чтобы лучше понимать характер и серьезность ситуации.

#### Критерии приемки

1. КОГДА бот отправляет сообщение о нарушении, ТО он ДОЛЖЕН включать полное название статьи УК РФ
2. КОГДА отображается нарушение, ТО бот ДОЛЖЕН показывать полную информацию о наказании
3. КОГДА есть цитата из анализируемого текста, ТО бот ДОЛЖЕН включать ее в сообщение с выделением
4. КОГДА показывается уровень серьезности, ТО бот ДОЛЖЕН использовать эмодзи-индикаторы (🟢 1-3, 🟡 4-6, 🔴 7-10)
5. КОГДА уровень доверия ниже 70%, ТО бот ДОЛЖЕН добавлять предупреждение о неопределенности

### Требование 2

**Пользовательская история:** Как администратор чата, я хочу видеть статистику нарушений по пользователям, чтобы принимать решения о модерации.

#### Критерии приемки

1. КОГДА запрашивается статистика по пользователям, ТО бот ДОЛЖЕН показывать список пользователей с количеством нарушений
2. КОГДА отображается статистика пользователя, ТО бот ДОЛЖЕН группировать нарушения по статьям УК РФ
3. КОГДА показывается информация о пользователе, ТО бот ДОЛЖЕН включать общий уровень риска
4. ЕСЛИ у пользователя есть нарушения высокой серьезности, ТО бот ДОЛЖЕН выделять их особо

### Требование 3

**Пользовательская история:** Как модератор, я хочу видеть общую статистику нарушений за определенный период, чтобы отслеживать динамику в чате.

#### Критерии приемки

1. КОГДА запрашивается статистика за период, ТО бот ДОЛЖЕН показывать общее количество нарушений
2. КОГДА отображается периодическая статистика, ТО бот ДОЛЖЕН группировать нарушения по статьям УК РФ
3. КОГДА показывается статистика, ТО бот ДОЛЖЕН включать средний уровень серьезности
4. КОГДА есть тренды, ТО бот ДОЛЖЕН показывать изменения по сравнению с предыдущим периодом

### Требование 4

**Пользовательская история:** Как пользователь бота, я хочу видеть общую статистику нарушений за все время, чтобы понимать общую картину активности в чате.

#### Критерии приемки

1. КОГДА запрашивается общая статистика, ТО бот ДОЛЖЕН показывать топ-5 самых частых нарушений
2. КОГДА отображается общая статистика, ТО бот ДОЛЖЕН показывать топ-5 пользователей с наибольшим количеством нарушений
3. КОГДА показывается статистика, ТО бот ДОЛЖЕН включать общий уровень риска чата
4. КОГДА есть критические нарушения, ТО бот ДОЛЖЕН показывать их отдельно

### Требование 5

**Пользовательская история:** Как пользователь Telegram, я хочу получать сообщения в удобном для чтения формате с использованием HTML разметки Telegram.

#### Критерии приемки

1. КОГДА бот отправляет сообщение, ТО он ДОЛЖЕН использовать HTML разметку для структурирования
2. КОГДА отображается информация о статье, ТО бот ДОЛЖЕН выделять номер статьи тегом `<b>` (жирный)
3. КОГДА показывается цитата, ТО бот ДОЛЖЕН использовать тег `<i>` (курсив) или `<code>` для выделения
4. КОГДА сообщение длинное, ТО бот ДОЛЖЕН разбивать его на логические блоки с эмодзи-разделителями
5. КОГДА нужно выделить важную информацию, ТО бот ДОЛЖЕН использовать теги `<u>` (подчеркивание) или `<s>` (зачеркивание) по необходимости
